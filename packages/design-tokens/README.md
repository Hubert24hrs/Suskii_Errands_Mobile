# design-tokens

`tokens.json` is the web mirror of the Flutter design tokens in
`packages/suskii_design/lib/src/tokens/` (colors, spacing, radius, typography, motion, blur). The
two are a single source of truth split across platforms: **any change must be made in both places
together**. All brand values are placeholders ("Aurora") — a rebrand means editing this file and
the corresponding `suskii_design` token files, nothing else. Contrast is checked by
`packages/suskii_design/test/design_tokens_test.dart`.

- `tailwind-preset.ts` — the one Tailwind preset all three Next.js apps use (`presets: [preset]`).
- `tokens.css` — CSS custom properties generated by `node build-css.mjs` (brand colours, gradient
  and glass per colour scheme, dark-first). Imported by each app's `globals.css`. CI runs
  `node build-css.mjs --check`, so a token change without regenerating fails.
- Fonts: Sora (display) and Manrope (body), both SIL OFL, loaded with `next/font/local` from
  `packages/suskii_design/assets/fonts`, the same files the Flutter app bundles.
